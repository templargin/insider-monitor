insider-monitor

Daily small-cap insider purchase screener. Form 4 filings filtered to:

  • Transaction code P (open-market purchase) only
  • One insider ≥ $100k in the filing bucket — two insiders at $60k each do not qualify
  • Enterprise value < $1B (basic shares)
  • TTM revenue > 0

The list is only what met all four. Issuers the screen cannot apply to — registered funds, 20-F filers, companies yet to file a first report — are left out rather than listed as unknowns. See About.
